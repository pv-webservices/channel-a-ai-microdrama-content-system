# Production Workspace

Canonical asset areas:
- `ideas/`
- `scripts/`
- `storyboards/`
- `characters/`
- `visual-prompts/`
- `video-prompts/`
- `voiceovers/`
- `sound-design/`
- `captions/`
- `approved/`
- `published/`
- `examples/`

For traceability, a complete active video may live in one `VID-####/` directory following the example structure.

Generated binary media is ignored by Git by default.
