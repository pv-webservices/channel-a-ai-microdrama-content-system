# Visual Review

Check generated stills/keyframes before they become approved Remotion source assets:
- Character IDs match sheets
- face/hair/wardrobe/accessories remain stable
- environment geography is coherent
- anatomy and object interactions are believable
- key actions are phone-readable in the selected still
- visual style is consistent
- captions/UI will not hide critical information
- each accepted source receives a stable Asset ID
- source type is recorded: **image** or **graphic**
- no AI-generated video asset is accepted into active production

If a scene needs more temporal information than one still can communicate, generate an additional approved still/keyframe and let Remotion sequence/animate those images. Do not solve the gap with an AI video model.

Only approved image/graphic assets should be mapped into the Remotion manifest. Log recurring defects for later evidence-based Skill improvement.
