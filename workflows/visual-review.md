# Visual Review

Check generated keyframes/shots before they become approved Remotion source assets:
- Character IDs match sheets
- face/hair/wardrobe/accessories remain stable
- environment geography is coherent
- anatomy and object interactions are believable
- key actions are phone-readable
- camera movement is motivated
- visual style is consistent
- captions/UI will not hide critical information
- each accepted source receives a stable Asset ID
- source type is recorded: image, video or graphic
- accidental source audio is identified; generated video audio is not approved by default

Only approved assets should be mapped into the Remotion manifest. Log recurring defects for later evidence-based Skill improvement.
