# Content Production Workflow — Phase 1

No video auto-publishes in Phase 1. **AI video-generation models are prohibited.** Approved still images/graphics are transformed into finished video exclusively through Remotion.

## Phase A — Concept
1. Idea Discovery — generate 10–20 diverse concepts.
2. Concept Scoring — score for internal prioritization.
3. Human Concept Selection — choose what advances.

## Phase B — Story
4. Hook Development — create several honest 1–3 second openings.
5. Micro-Drama Script Writing — hook → situation → conflict → escalation → turning point → payoff → resolution.
6. Retention Review — diagnose pacing, predictability, exposition and visual stagnation.
7. Human Script Approval — no production assets before approval.

## Phase C — Pre-production
8. Character Consistency — create stable Character IDs and sheets.
9. Storyboard — create scene timing, action, camera, continuity, audio intent and Remotion handoff fields.
10. Image Prompt Generation — create continuity-reference and scene-keyframe prompts.
11. Remotion Motion Planning — translate each storyboard scene into deterministic still-image motion, cuts, scale/position transforms, caption exclusions and optional additional-keyframe requirements.

## Phase D — Asset Production
12. Visual Asset Production — generate, review and approve **images/graphics only**. No AI video generation.
13. Voiceover Production — produce approved narration/dialogue.
14. Sound Design Production — create/approve ambience, SFX, music direction and silence map.

## Phase E — Remotion Post-production
15. Remotion Composition & Assembly — convert storyboard + approved still assets + motion plan + voice + sound + captions into a frame-accurate 9:16 composition.
16. Render Validation — render a candidate MP4 and verify technical integrity, timing, missing assets, sync and safe areas before editorial QC.

## Phase F — Release & Learning
17. Quality Control — strict story, retention, visual, audio, render and platform review.
18. Human Final Approval — final editorial decision.
19. Publish Manually — upload to the intended account/platform.
20. Record Analytics — use measured values only.
21. Postmortem & Skill Improvement — update learnings only after sufficient evidence.

## Non-negotiable visual rule
- AI image generation is allowed.
- AI video-generation models are not allowed.
- Active Remotion visual assets are `image`, `graphic`, or `none` while incomplete.
- Narrative motion is produced through Remotion transforms, cuts, holds, captions, optional layering/parallax, and additional approved still keyframes when needed.
- Do not simulate missing story clarity with excessive effects.

## Gate rules
- Concept gate: human chooses what gets scripted.
- Script gate: no asset production before script approval.
- Asset gate: only approved image/graphic source assets enter Remotion.
- Render gate: candidate render must pass Render Validation before final QC.
- Final gate: QC supports but never replaces human approval.
- Analytics gate: no Skill change from one result.

## Artifact contract
Prefer one VID-#### project folder containing the full chain. The Remotion data manifest must reference the same scene IDs, asset IDs, timing and approved audio/caption decisions as production artifacts.

## Remotion ownership boundary
Remotion owns all video construction: scene sequencing, still-image placement, scale/position motion, transitions, captions, audio placement, timing, overlays, safe-area treatment and final encoding. It does not own story ideation, character design, image generation, voice generation, publishing decisions or analytics interpretation.
