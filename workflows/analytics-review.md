# Analytics Review

## Per-video
After data is mature enough for the review window:
1. update measured values,
2. inspect hook/retention progression,
3. note strongest/weakest moments,
4. complete a postmortem.

## Periodic channel review
1. group comparable videos,
2. inspect sample sizes,
3. compare hook/story/pillar/length/style dimensions,
4. identify confounders,
5. propose hypotheses,
6. move only validated observations to `analytics/learnings.md`,
7. version Skills only when evidence supports a specific rule change.

Never fill missing metrics with estimates disguised as platform data.
