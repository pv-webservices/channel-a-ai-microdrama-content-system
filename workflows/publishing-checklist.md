# Publishing Checklist — Manual

- [ ] Final human approval recorded
- [ ] Render Validation is PASS
- [ ] Final QC is PASS or all required changes are resolved and rechecked
- [ ] Publishing file is the same approved render
- [ ] 9:16 framing verified
- [ ] captions stay in safe/readable area
- [ ] no third-party watermark
- [ ] rights to voice, music and visual inputs verified
- [ ] no fake real-person event
- [ ] synthetic-media disclosure handled if current platform policy requires it
- [ ] title/caption accurately represents the story
- [ ] correct account/platform selected
- [ ] publish date/time recorded
- [ ] analytics row created; performance fields stay blank until measured
