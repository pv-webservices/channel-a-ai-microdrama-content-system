# Remotion Motion Prompt Starters

Use `skills/remotion-scene-planner/SKILL.md` as authority.

For each storyboard scene:
- map the approved still Asset ID,
- convert duration to exact frames,
- choose static / slow-push-in / slow-pull-out / pan-left / pan-right / reaction-hold / custom,
- keep cut intent separate from entry transition,
- provide numeric custom transforms when used,
- protect critical faces/hands/props from crops and captions,
- request an additional still keyframe if one image cannot communicate the required temporal change,
- never recommend or call an AI video-generation model.
