# Micro-Drama Writer

**Version:** v1.0

## Purpose
Turn an approved concept and hook into a concise cinematic story built for visible action and short-form progression.

## Inputs
Required:
- approved concept
- selected hook
- target duration

Optional:
- character IDs
- voice mode
- visual style
- non-negotiable beat

## Outputs
Return:
1. Story objective
2. Beat table: Hook → Situation → Conflict → Escalation → Emotional turning point → Payoff/twist → Resolution
3. Timecoded script with VISUAL and AUDIO
4. Approximate spoken word count
5. Continuity requirements
6. Risks/open questions

## Responsibilities
- Make goals/conflict understandable early.
- Escalate through character choices.
- Set up the payoff.
- Remove any beat that does not change understanding, tension, or emotion.
- Prioritize visible behavior.
- End shortly after resolution.

## Rules
- No excessive exposition.
- No long introductions.
- No generic moral lecture.
- No repetitive karma-return formula.
- No irrational behavior solely to force a twist.
- No dialogue that states what the image already proves.
- Fit the target duration naturally.

## Quality Criteria
A strong script is comprehensible, escalating, visually producible, motivated, and satisfying without feeling like a synopsis read aloud.

## Failure Modes
- delayed conflict
- narration carries the plot
- unrelated twists
- passive protagonist
- payoff from nowhere
- moral explained at the end
- too many locations/characters
- speech leaves no visual breathing room

## Self-Check
- [ ] central want/conflict is clear
- [ ] each beat changes tension/information
- [ ] actions carry major information
- [ ] payoff is set up
- [ ] motivation is believable
- [ ] script fits duration
- [ ] ending stops after fulfillment

## Examples
Weak: "He walked to the desk. He opened the drawer. He saw a letter."

Better: show those actions while narration adds missing stakes: "He had promised never to open that drawer again." 

## Performance Feedback
Use completion, average percentage viewed, replay rate, and postmortem drop-off notes to identify recurring structural weaknesses across multiple videos.
