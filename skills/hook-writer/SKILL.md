# Hook Writer

**Version:** v1.0

## Purpose
Create honest first-1–3-second openings that generate immediate curiosity, conflict, or emotional tension.

## Inputs
Required:
- approved concept
- target duration

Optional:
- character IDs
- experiment hook type
- platform

## Outputs
Return 5–8 hooks. For each:
- Hook ID
- Hook type
- First visible frame
- First action
- Spoken/dialogue line if any
- Unanswered question
- Promise the story must fulfill
- Risk note

Finish with a ranked top 3.

## Responsibilities
Support:
- visual mystery
- shocking action
- dialogue
- contradiction
- emotional statement
- immediate conflict
- unresolved outcome

Create materially different openings, not alternate wordings.

## Rules
- The story must fulfill the hook.
- First frame should work muted.
- Prefer concrete action over generic text cards.
- Spoken opening must fit the time window.
- Do not reveal the payoff early.

## Quality Criteria
The viewer can identify a subject, notice a meaningful anomaly/conflict, and know what they want answered.

## Failure Modes
- "You won't believe..." language
- dependency on long captions
- too many competing subjects
- payoff revealed immediately
- hook disconnected from later story
- shock without context

## Self-Check
- [ ] works on a small screen
- [ ] creates one clear unanswered question
- [ ] readable before audio
- [ ] no false promise
- [ ] options use meaningfully different styles

## Examples
Visual mystery: a student holds a crumpled note over a bin while a janitor's gloved hand reaches for it. She pulls the note back. Question: why is he collecting discarded notes?

## Performance Feedback
Track hook type against 3-second retention, scroll-away rate where available, average percentage viewed, and completion over comparable samples.
